# Full-vision dashboard (design exploration)

Design mockups of the Facto command centre once the roadmap phases are built: estate map, approvals, AI gateway with privacy routing, agents, home, backups, automations and one activity timeline.

- `desktop.dc.html`: 1440 px page.
- `phone.dc.html`: 390 px phone layout.

Both are Design Component files (self-contained HTML with a `support.js` runtime from the design canvas), so they open in the design canvas, not directly in a browser. All numbers, node names (Mac mini, Raspberry Pi, Cloud VPS) and events are illustrative sample data, not live state. This is not an accepted design: the lite dashboard in `apps/dashboard` and `theme.md` remain the source of truth until an ADR says otherwise.
